## 十二、协作规则速查（文档 §19）

- **分支**：`main` 保护 + `feature/xxx` + PR（≥1 人 review，CI 绿才合）
- **Commit**：Conventional Commits（`feat:` / `fix:` / `refactor:` / `test:` / `docs:`）
- **DoD**：代码合入 main + 接口契约文档同步 + 单测通过 + Owner 在迭代评审演示
- **关键模块双人制**：`core/pipeline.py`、`moderation/workflow.py` 必须 Owner + Backup 两人可维护
- **节奏**：每周一次站会，每两周一次迭代评审；任务粒度 ≤ 3 天；每个迭代预留 20% 缓冲

## 十三、常用命令速查

```bash
# 拉起 / 停止（项目根目录执行）
docker compose -f deploy/docker-compose.yml up -d --build
docker compose -f deploy/docker-compose.yml down          # 保留数据
docker compose -f deploy/docker-compose.yml down -v       # 清空数据（慎用）

docker compose -f deploy/docker-compose.yml ps
docker compose -f deploy/docker-compose.yml logs -f app   # worker / nginx 同理

  --student-no 20230001 --nickname 管理员 --email admin@stu.example.edu.cn
```
