## 一、演示主线剧本（约 8-10 分钟）

> 每步：操作 → 预期画面 → 讲解要点。

### 第 1 幕 · 个人库 RAG：30 秒从上传到可问答（约 3 分钟）

1. **登录**：浏览器打开 http://localhost:8080/login ，学号 20260001 + 邮箱，验证码页面直接回显（讲解：开发期假通道，生产接 CAS 或真实邮件）。
   → 预期：登录成功回首页，导航栏显示昵称「演示-张三」。
   → 讲解：邮箱降级认证 + Redis Session/JWT 双通道；RBAC 四角色。
2. **进入个人知识库** `/library`：新建学期「2026 秋」→ 新建课程「计算机操作系统」。
   → 讲解：个人库严格数据隔离（越权 404）。
3. **上传课件**：点「上传资料」，选一份真实课件（pdf/pptx/docx/md 均可，建议 md 或 pdf，<50MB）。
   → 预期：202 异步解析，3 秒轮询看到「解析中 → 已完成」。
   → 讲解：四格式解析器 → 语义切块（400-600 字 + overlap）→ 本地 bge 向量化（模型烘焙进镜像，运行时离线）→ 章节树自动构建 + AI 校验（附加层，不阻塞）。
4. **AI 问答**：点「AI 问答」，提问预演问题 Q1（见问题清单）。
   → 预期：打字指示器 → 逐字流式回答 → 下方引用卡片（章节/小节/上传者署名）。
   → 讲解：BM25+语义 RRF 融合检索、SSE 流式、引用只保留真实 chunk（防幻觉约束）。
5. **溯源高亮**：点击任一引用卡片 → 跳原文溯源页，对应文本块锚点高亮。
   → 讲解：块级精准溯源是「结构化 RAG」相对长上下文方案的差异化能力。
6. **反幻觉演示**：提问预演问题 Q9（资料中未提及）。
   → 预期：AI 明确声明「资料中未提及」。
7. **复习工具（加分项）**：回 `/library` 点「复习工具」→ 选章节生成复习大纲 → 生成考点习题。
   → 讲解：同一套检索底座支撑问答/大纲/习题三种学习场景。

### 第 2 幕 · 公共库：投稿到上架的三级审核（约 2.5 分钟）

8. **投稿**：回 `/library`，在已解析文档上点「投稿到公共库」，填简介、选挂载章节。
   → 预期：201，提示已进入审核。
9. **自动预检**（讲解用，无需操作）：格式/MD5 查重/敏感词 + AI 初评（真实模型打分）。
10. **协审**：退出，换协审员 20260101 登录 → 导航「协审」→ 队列中看到该资源 → 点开看预检三分与 AI 初评 → 「通过」。
    → 讲解：协审员按专业优先指派 2 人、多数决；48h 超时自动重指派。
11. **终审**：换管理员 20230001 登录 → 导航「终审」→ 看协审意见聚合 → 「通过」。
    → 预期：资源上架；投稿人收到审核通过通知、贡献分 +20。
    → 讲解：终审通过复制派生 public 副本（个人库原件不动）、章节摘要回填启用粗召回。

### 第 3 幕 · 社区闭环：检索 → 问答 → 激励（约 2.5 分钟）

12. **他人视角检索**：换另一位同学账号（或就用协审员账号）→ 课程空间 → 数据结构 → 资料库 Tab 看到刚上架的资源 → 在线预览 / 下载（下载扣贡献分，上传者得 80% 分成）。
13. **公共库问答**：课程空间点「AI 问答」（或 `/library/chat` 切公共库）提问相关问题。
    → 预期：回答引用中展示原作者署名（讲解：激励署名权）。
14. **问答贴 + AI 首答**：到「知屿问答」发帖提问 → 稍候 AI 首答自动生成（带引用溯源、「AI 生成仅供参考」署名）→ 同学评论 → 帖主采纳（+15）。
    → 演示捷径：直接打开种子帖 `/posts/30`（二叉树遍历）展示 AI 首答与已采纳评论。
15. **激励体系**：个人中心 `/me` → 成长看板（等级/贡献分/信用分）→ 课程空间「贡献榜」Tab（前三名奖牌色）。
    → 讲解：贡献分 = 上传/被采纳/精华/悬赏结算；可兑换 AI 额度，也可配置自定义模型 Key（Fernet 加密存储）。

### 第 4 幕 · 治理与运营（约 1.5 分钟，管理员账号）

16. **管理后台** `/admin`：六个 Tab 快速过——审核终审入口 / 空间管理（专业导入、课程审批）/ 用户治理（角色任命、信用裁决 ±100 限幅）/ 平台配置（AI 日额度、兑换汇率、协审时限在线调整，DB 覆盖 .env + 审计留痕）/ 举报处理 / 运营看板（ECharts 7 天趋势）。
17. **信用阶梯（讲解用）**：信用 <80 行为冷却 429 / <60 禁言 403 / <40 冻结 401，回升自动解除。
18. **经验长廊与资料求援**：`/boards/experience`（结构化模板、AI 摘要、标签云、精华区）；`/boards/bounty`（悬赏托管 → 评论响应 → 采纳结算全额转账，禁自采纳、结算后禁改采）。

### 收尾（30 秒）

19. 回到首页：平台数据、动态流（关注课程新资料 + 近 7 天热帖）。
    → 一句话总结：「学生社区共建为内容之源、结构化 RAG-AI 为学习引擎、认证+审核+激励为信任之基」。
