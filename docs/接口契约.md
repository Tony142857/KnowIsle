# 知屿 KnowIsle 接口契约

- 版本：v1.4（2026-10-26 全量复核校准）
- 事实来源：以 `app/api/` 下 18 个路由文件（`auth / users / courses / library / documents / resources / chat / review / review_tasks / posts / votes / favorites / follows / feed / reports / notifications / search / admin`）的代码为唯一事实来源；路由统一挂载于 `/api` 前缀（`app/main.py`）。按方法-路径操作归并尾斜杠别名后共 **87 个操作、75 个资源路径**。与《知屿-智能课程知识社区-项目文档.md》§12.1 的差异见文末专节。

## 通用约定

**鉴权双通道**（`app/identity/rbac.py`）：每个请求优先解析 `Authorization: Bearer <JWT>`（API 通道，由 `POST /api/auth/token` 凭会话签发），其次解析 Session Cookie（页面通道，登录接口写入，HttpOnly + SameSite=Lax）。两者任一有效即视为登录。

**角色模型**：`student / reviewer / builder / admin` 四角色。`reviewer` 与 `builder` 为平行特权角色（互不蕴含）；`admin` 放行所有角色门控。表中「鉴权」列：`匿名` = 无需登录；`登录` = 任意已登录用户；`reviewer` / `builder` / `admin` = 需对应角色（admin 恒可）。

**错误语义**：

| 状态码 | 含义 |
| --- | --- |
| 401 | 未登录 / 会话过期 / 账号冻结（`get_current_user` 统一抛出）；邮箱验证码错误也返回 401 |
| 403 | 仅一种场景：禁言用户执行发言动作（发帖 / 评论，`assert_can_speak`），响应带解禁时间 |
| 404 | 资源不存在，**或存在但当前用户无权访问**——数据级越权与角色门控不足一律返回 404 而非 403，不暴露资源存在性（§3.2 原则） |
| 422 | 参数校验或业务规则校验失败（含 pydantic 校验） |
| 429 | 频率 / 额度超限：AI 日额度耗尽、邮箱验证码限流、低信用用户动作冷却 |
| 500 | 异步任务入队失败等内部错误（发帖 / 上传的入队补偿路径） |
| 501 | 功能预留未启用（当前仅 CAS/OIDC 两个路由） |
| 502 | 上游 AI / 检索服务故障（复习工具直接返回；问答走 SSE `error` 事件） |
| 409 | 仅一处：Office 资源预览产物生成中（`GET /api/resources/{id}/preview`） |

**越权 404 原则**：个人库（课程 / 文档）强制 `owner_id` 过滤，公共库强制 `scope='public'` 且 `status='active'`；不满足时与「不存在」同样返回 404，响应体恒为 `{"detail": "Not Found"}`，调用方无法区分。

**尾斜杠双注册**：`POST/GET /api/documents`、`/api/posts`、`/api/votes`、`/api/favorites`、`/api/follows`、`/api/notifications`、`/api/library`、`/api/resources` 同时注册了带 / 不带尾斜杠两条路由（nginx 反代下 307 会丢失端口），本文一律写无尾斜杠形式。

**分页约定**：列表接口统一 `page`（≥1，默认 1）+ `size`（默认 20，上限 100；`/api/resources` 与 `/api/search` 上限 50），响应含 `total` / `items`。

**幂等开关语义**（收藏 / 关注 / 举报）：重复 `POST` 返回 200 + `created=false`（非 409）；`DELETE` 幂等 204（无记录也 204）。

### SSE 事件序列：`POST /api/chat`

响应为 `text/event-stream`（sse-starlette `EventSourceResponse`），每帧 `data: <JSON>`。正常序列：

```
data: {"type": "token", "text": "分页存储管理"}        # 逐 token 流出，0..N 帧
data: {"type": "citations", "items": [                # 正文流完后 1 帧；引用编号映射溯源信息
  {"chunk_id": "pub_d45_00007", "chapter": "第三章 内存管理", "page_num": 78,
   "source_scope": "public", "uploader": "知屿用户_1024"}]}
data: {"type": "done", "token_usage": 1520, "latency_ms": 2340}   # 收尾 1 帧
```

- `token` × N → `citations` × 1 → `done` × 1 为成功路径；引用映射查询异常时 `citations` 降级为空数组，不中断流。
- 检索 / LLM 异常时不抛 HTTP 错误，而是 yield `{"type":"error","message":"..."}` 后结束流（此时无 `done`）。
- **流前校验以普通 JSON 错误返回**：未登录 401、官方额度耗尽 429、课程越权 404、参数非法 422——客户端需先检查 HTTP 状态码再按 SSE 解析。
- `done` 帧发出前完成 qa_logs 落库与官方额度扣减（同一事务；落库失败仅记日志不影响已流出内容）。
